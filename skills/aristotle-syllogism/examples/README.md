# Aristotelian syllogisms · 아리스토텔레스식 삼단논법

Decide whether the conclusion must hold whenever the stated premises hold.

주어진 전제가 모두 참일 때 결론도 반드시 참인지 판단합니다.

| Level | English | 한국어 |
| --- | --- | --- |
| `light` | Identify the premises and terms. Flag a missing premise if the conclusion needs it. [Example](light.md) | 전제와 주요 용어를 밝힙니다. 결론에 필요한 전제가 빠졌으면 짚습니다. [예제](light.ko.md) |
| `standard` | Check the scope of “all,” “some” and negation. Distinguish validity from evidence for the premises. [Example](standard.md) | ‘모두’, ‘일부’, 부정이 미치는 범위를 살피고 추론의 타당성과 전제 자체의 근거를 구분합니다. [예제](standard.ko.md) |
| `strict` | For an invalid inference, give a case where the premises hold but the conclusion fails. For a valid one, explain why that is impossible. [Example](strict.md) | 타당하지 않으면 전제가 참이고 결론이 거짓인 반례를 듭니다. 타당하면 그런 반례가 불가능한 이유를 설명합니다. [예제](strict.ko.md) |
