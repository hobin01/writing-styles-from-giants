# IETF RFC-style specifications · RFC식 프로토콜 명세

Describe protocol behavior so an implementer can tell who must act, under which condition and what outcome to expect.

프로토콜 구현자가 누가 어떤 조건에서 무엇을 해야 하고 그 결과가 무엇인지 알 수 있게 명세를 씁니다.

| Level | English | 한국어 |
| --- | --- | --- |
| `light` | Clarify the scope and terms. Preserve what is required, recommended or optional. [Example](light.md) | 범위와 용어를 밝히고 의무·권고·선택을 구분합니다. [예제](light.ko.md) |
| `standard` | Organize behavior into a specification and distinguish references needed for implementation from background material. [Example](standard.md) | 동작을 명세 형태로 정리하고 구현에 필요한 참조와 배경 자료를 구분합니다. [예제](standard.ko.md) |
| `strict` | Check the actor, condition and observable result of each requirement. Examine security and reference gaps. [Example](strict.md) | 각 요구사항의 주체, 조건, 관찰 가능한 결과를 확인하고 보안이나 참조에서 빠진 내용을 점검합니다. [예제](strict.ko.md) |
