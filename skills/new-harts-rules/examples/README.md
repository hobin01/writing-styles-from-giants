# New Hart’s Rules · 출처를 확인하는 영문 교정

Resolve English editorial choices using the publication’s house style and verified book passages. The Korean example gives Korean reasons for an English edit.

출판물의 자체 표기 기준과 책에서 직접 확인한 근거를 바탕으로 영문을 교정합니다. 한국어 예제에서는 영문을 고친 이유를 한국어로 설명합니다.

| Level | English | 한국어 |
| --- | --- | --- |
| `light` | Identify the edition and verify the choices the requested passage needs. [Example](light.md) | 판본을 확인하고 요청받은 구절을 고치는 데 필요한 근거를 찾습니다. [예제](light.ko.md) |
| `standard` | Apply supported choices consistently and distinguish house decisions from verified book rules. [Example](standard.md) | 근거가 있는 표기를 일관되게 적용하고, 자체 편집 기준과 책에서 확인한 규칙을 구분합니다. [예제](standard.ko.md) |
| `strict` | Check every editorial choice in scope and leave unsupported rulings open. [Example](strict.md) | 편집 범위 안에서 각 표기의 근거를 점검하고, 판단할 자료가 부족한 부분은 보류합니다. [예제](strict.ko.md) |
