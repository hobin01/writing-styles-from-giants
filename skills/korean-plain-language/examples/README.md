# Korean plain language · 쉬운 한국어

Edit Korean wording so the reader can identify the actor, action and conditions. The English example explains a Korean edit in English.

누가 무엇을 어떤 조건에서 하는지 알 수 있도록 한국어 문장을 다듬습니다. 영어 예제에서도 편집 대상은 한국어이고, 이유를 영어로 설명합니다.

| Level | English | 한국어 |
| --- | --- | --- |
| `light` | Clarify referents, particles and unfamiliar terms while preserving the existing voice. [Example](light.md) | 원래 어투를 유지하면서 지시 대상과 조사의 범위를 분명히 하고 낯선 용어를 풉니다. [예제](light.ko.md) |
| `standard` | Also check speech level, permission versus obligation, and which condition belongs to each action. [Example](standard.md) | 높임의 정도, 허용과 의무의 차이, 각 행동에 딸린 조건까지 확인합니다. [예제](standard.ko.md) |
| `strict` | Recheck all applicable rules across the revised text, including repeated terms and referents. [Example](strict.md) | 고친 문장 전체를 다시 읽으며 되풀이되는 용어와 지시 대상까지 일관되는지 점검합니다. [예제](strict.ko.md) |
