# Boring Professor · 기술 강의식 설명

Explain a technical mechanism literally. Define terms before using them, follow their dependencies and leave out jokes and metaphors.

농담과 비유 없이 기술 원리를 설명합니다. 용어의 뜻을 먼저 밝히고, 앞선 지식이 필요한 개념은 그다음에 설명합니다.

| Level | English | 한국어 |
| --- | --- | --- |
| `light` | Define the essential terms and put the steps in dependency order. [Example](light.md) | 꼭 필요한 용어를 정의하고 앞 단계부터 순서대로 풉니다. [예제](light.ko.md) |
| `standard` | Check which conclusions the evidence supports and under which conditions. [Example](standard.md) | 각 결론에 근거가 있는지, 어떤 조건에서 성립하는지 확인합니다. [예제](standard.ko.md) |
| `strict` | Check every relevant dependency and boundary, including what the data leave undetermined. [Example](strict.md) | 필요한 전제와 적용 범위를 하나씩 점검하고, 자료만으로 판단할 수 없는 부분을 밝힙니다. [예제](strict.ko.md) |
