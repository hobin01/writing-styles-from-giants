# Google-inspired design docs · 구글식 설계 문서

Describe a proposed system change so reviewers can evaluate its goals, alternatives, trade-offs and open decisions.

설계 검토자가 시스템 변경의 목적과 대안, 각 선택의 득실, 아직 결정하지 못한 사항을 판단할 수 있게 씁니다.

| Level | English | 한국어 |
| --- | --- | --- |
| `light` | State the context, goals and proposed behavior. [Example](light.md) | 배경과 목표, 제안한 시스템이 어떻게 동작할지 설명합니다. [예제](light.ko.md) |
| `standard` | Compare credible alternatives and distinguish the proposal from decisions already approved. [Example](standard.md) | 현실적인 대안들을 비교하고 제안 단계인 내용과 이미 승인된 결정을 구분합니다. [예제](standard.ko.md) |
| `strict` | Trace major choices to goals and test material failure cases. Record unresolved evidence or disagreement. [Example](strict.md) | 주요 선택을 목표와 대조하고 중요한 실패 상황을 검토합니다. 근거가 부족하거나 합의되지 않은 부분을 남깁니다. [예제](strict.ko.md) |
