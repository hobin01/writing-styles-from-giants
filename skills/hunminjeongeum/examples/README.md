# Hunminjeongeum · 훈민정음식 설명

Open with the difficulty that made the writing necessary. Develop a response and return to that difficulty in the conclusion.

글이 필요한 이유부터 밝힙니다. 누가 어떤 어려움을 겪는지 짚고, 본문에서 해법을 설명한 뒤 결론에서 처음의 문제로 돌아갑니다.

| Level | English | 한국어 |
| --- | --- | --- |
| `light` | Make the difficulty and purpose clear in the opening. [Example](light.md) | 누가 왜 이 설명을 필요로 하는지 첫머리에 밝힙니다. [예제](light.ko.md) |
| `standard` | Connect each part of the explanation to the problem and conclude within the evidence. [Example](standard.md) | 본문의 설명을 처음의 문제와 연결하고 근거가 뒷받침하는 범위에서 결론을 맺습니다. [예제](standard.ko.md) |
| `strict` | Trace the opening question through the whole document and fix gaps or digressions. [Example](strict.md) | 처음 밝힌 목적이 본문과 결론까지 이어지는지 살피고, 논리가 건너뛴 곳이나 곁가지로 샌 부분을 고칩니다. [예제](strict.ko.md) |
