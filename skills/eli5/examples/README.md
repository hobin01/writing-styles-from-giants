# ELI5 · 다섯 살 아이에게 설명하기

Write what an adult could read aloud to a child. Start with something the child can picture and explain one change at a time.

어른이 아이에게 그대로 읽어줄 말을 씁니다. 아이가 떠올릴 수 있는 장면에서 출발해 무엇이 어떻게 달라지는지 하나씩 설명합니다.

| Level | English | 한국어 |
| --- | --- | --- |
| `light` | Start with a familiar object or event and show the steps that produce the result. [Example](light.md) | 익숙한 물건이나 사건에서 시작해 결과가 생기는 과정을 보여줍니다. [예제](light.ko.md) |
| `standard` | Also check whether the words and any analogy fit the child and where the simplification stops holding. [Example](standard.md) | 아이에게 익숙한 말인지 확인하고, 쉽게 풀어 쓴 말이나 비유가 어디까지 맞는지 살핍니다. [예제](standard.ko.md) |
| `strict` | Check each step, quantity and qualification against the source, including what the explanation leaves open. [Example](strict.md) | 각 단계와 수량, 조건을 원문에 대조하고 아직 답할 수 없는 부분을 확인합니다. [예제](strict.ko.md) |
