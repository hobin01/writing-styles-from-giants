# Amazon six-page narrative · 아마존식 의사결정 메모

Give reviewers a narrative they can read before a decision. Explain what needs deciding, which evidence supports the recommendation and where it might fail.

결정을 앞둔 사람이 혼자 읽고 판단할 수 있는 메모를 씁니다. 무엇을 결정해야 하는지, 추천안의 근거는 무엇인지, 어떤 조건에서 결론이 달라질지 설명합니다.

| Level | English | 한국어 |
| --- | --- | --- |
| `light` | Clarify the decision and its context. Repair unsupported claims. [Example](light.md) | 결정할 사항과 배경을 밝히고 근거가 없는 주장을 바로잡습니다. [예제](light.ko.md) |
| `standard` | Connect the recommendation to evidence and uncertainty within the requested length. [Example](standard.md) | 요청한 분량 안에서 추천안의 근거와 불확실한 점을 설명합니다. [예제](standard.ko.md) |
| `strict` | Trace each major conclusion to evidence or an assumption. Check the page limit when the layout is available. [Example](strict.md) | 주요 결론마다 근거나 가정을 확인합니다. 지면 형식이 정해져 있으면 실제 분량도 확인합니다. [예제](strict.ko.md) |
