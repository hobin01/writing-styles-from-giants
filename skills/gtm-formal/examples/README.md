# GTM-style formal mathematics · 수식과 증명으로 설명하기

State a mathematical claim with explicit domains, definitions and hypotheses, then derive it in justified steps. This project draws on the Graduate Texts in Mathematics series.

대상과 정의, 가정을 먼저 밝히고 각 단계에 근거를 붙여 명제를 증명합니다. Graduate Texts in Mathematics 시리즈에서 착안한 프로젝트 방식입니다.

| Level | English | 한국어 |
| --- | --- | --- |
| `light` | Define the notation and scope of the claim. Justify the main steps. [Example](light.md) | 기호와 명제가 적용될 범위를 정의하고 주요 추론의 근거를 밝힙니다. [예제](light.ko.md) |
| `standard` | Also interpret the symbols in words and test relevant boundary cases. [Example](standard.md) | 수식이 뜻하는 바를 말로 풀고, 경계에서도 명제가 성립하는지 확인합니다. [예제](standard.ko.md) |
| `strict` | Check every applicable case and identify remaining proof obligations. [Example](strict.md) | 해당하는 경우를 모두 점검하고, 증명을 끝내려면 무엇을 더 보여야 하는지 짚습니다. [예제](strict.ko.md) |
